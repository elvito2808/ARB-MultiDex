## معیارهای ادامه و پذیرش

- هر اصلاح SIM-01 همان شناسه را حفظ می‌کند و شماره بازنگری را افزایش می‌دهد. بازبین باید از SHA دقیق نتیجه استفاده کند و در تهیه همان بازنگری مشارکت نداشته باشد.
- SIM-01 Review-2 باید هر شش یافته گزارش `SIM-01-S2-review-1` را با شاهد پاسخ دهد: پوشش و سیاست کارمزد؛ اعتبارسنجی مقادیر و اتصال پاسخ به درخواست؛ هویت بازار و نسخه نگاشت؛ مسئولیت تازگی و بازیابی Cache؛ شکل خطا و هم‌بستگی درخواست؛ جداسازی حالت شبیه‌سازی و قواعد پذیرش دو مسیر.
- برای DEX-02-01، S2 بازبین اصلی مطابق ماتریس مسئولیت شاخه `agent-governance` است. بازبینی S5 یک بررسی تخصصی مکمل برای شواهد و مرز امنیتی است، نه جایگزین بازبینی فنی S2. این تفکیک، درخواست گزارش بسته برای بررسی S5 را نیز پوشش می‌دهد.
- Endpoint، Freshness policy و Fee coverage policy تا ثبت تصمیم معتبر در D-01/D-03، گزینه‌ها و محدودیت‌ها باقی می‌مانند. هیچ انتخاب ارائه‌دهنده یا تغییر دامنه از طریق استنباط Agent 0 انجام نمی‌شود.
- دامنه جاری مستندات، طراحی غیرعملیاتی و شبیه‌سازی با داده ساختگی است. LIVE، امضا، سفارش واقعی، انتقال دارایی و استفاده یا ثبت اطلاعات محرمانه خارج از دامنه هستند.
- Agent 0 هنگام تغییر وضعیت، بازنگری، SHA، پیوند شاهد، آزمون‌های اجراشده و اجرا‌نشده و اقدام بعدی را ثبت می‌کند. اگر SHA نتیجه تغییر کند، بازبینی بخش‌های متأثر باید روی SHA جدید ثبت شود.
