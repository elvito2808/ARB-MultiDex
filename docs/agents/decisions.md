# تصمیمات باز و وضعیت بسته‌ها

| شناسه | موضوع | وضعیت فعلی | مسئول تهیه شواهد |
|---|---|---|---|
| D-01 | DEX، شبکه، طرفین و روابط اولیه | انتخاب بازار مرجع فعلی برای DEX-02-01 بسته شد: Hedera Mainnet / SaucerSwap V1 / WHBAR-USDC / Pool انتخاب‌شده توسط مالک. انتخاب سایر DEXها، شبکه‌ها و روابط KuCoin همچنان باز است. | S1 و S2 |
| D-02 | زبان، معماری Runtime و ذخیره وضعیت | باز؛ پیش از پیاده‌سازی اجرایی باید پیشنهاد محدود و مستدل ارائه شود. | Agent 0 و S3 |
| D-03 | هزینه نهایی، آستانه، حجم، تازگی داده و اعتبار Quote | باز؛ برای DEX-02-01 شامل Gas، تبدیل HBAR به USDC، گردکردن BUY و زمان اعتبار Quote است. | S2 با شواهد S1 |
| D-04 | وضعیت نامعلوم، نهایی‌شدن معامله و سیاست Approval | باز؛ در مرحله مربوط به Execution بررسی می‌شود. | S3 و S5 |
| D-05 | مشاهده‌پذیری، نگهداری سوابق و اعلان‌ها | باز؛ قرارداد رویدادهای لازم برای DEX در برنامه تکمیل مشخص شده است. | S4 و S5 |

برای هر تصمیم بسته‌شده، تاریخ، گزینه‌ها، دلیل انتخاب، مرجع اختیار و اثر بر قراردادها ثبت شود. انتخاب ارائه‌دهندگان و تغییر دامنه پروژه به مالک پروژه تعلق دارد. متخصص‌ها گزینه و شاهد آماده می‌کنند.

## بسته‌های پذیرفته‌شده

- **SIM-01 Revision 3:** در سطح طراحی قرارداد Quote پذیرفته شد. گزارش پذیرش: [SIM-01 Agent 0 acceptance](../reviews/SIM-01-agent0-acceptance.md).
- **DEX-02-01 Revision 1:** تحقیق غیرعملیاتی بازار Hedera / SaucerSwap V1 پذیرفته شد؛ این پذیرش به معنی ساخته‌شدن Adapter یا تکمیل ماژول DEX نیست. گزارش پذیرش: [DEX-02-01 Agent 0 acceptance](../reviews/DEX-02-01-agent0-acceptance.md).

## بسته فعال DEX

برنامه تکمیل ماژول DEX در [DEX-module-completion-plan.md](../plans/DEX-module-completion-plan.md) ثبت شده است. مرحله بعد شامل تعیین تکلیف D-02 و D-03 و سپس ساخت Adapter خواندنی بازار مرجع است. مسئولیت‌ها و معیارهای پایان در همان برنامه مشخص شده‌اند.

نقش‌ها طبق [قواعد نقش‌ها](roles.md)، [ماتریس مسئولیت](responsibilities.md) و [تحویل دستی](handoff.md) اجرا می‌شوند. نقش‌های S1 تا S5 در این مخزن تحویل دستی دارند و اجرای خودکار از طریق AMS فرض نمی‌شود.
