# قرارداد تحویل دستی

Agent 0 بسته را در گفت‌وگو یا PR ثبت می‌کند و همراه نسخه مبنا و پیوند قواعد نقش به گیرنده می‌دهد. گیرنده دامنه را بررسی می‌کند و تحویل را می‌پذیرد یا مانع را با شاهد برمی‌گرداند. هر اصلاح به همان شناسه و با شماره بازنگری جدید برمی‌گردد.

```text
شناسه بسته / بازنگری:
فرستنده / گیرنده / بازبین:
شاخه و SHA مبنا:
هدف / اسناد و بندهای مرجع:
مسیرهای مجاز / خارج از دامنه:
وابستگی / تصمیم باز:
خروجی و معیار پذیرش:
وضعیت: واگذارشده | آماده بازبینی | نیازمند اصلاح | مسدود | پذیرفته‌شده
ارجاع نتیجه: SHA یا پیوند و مسیرها
شواهد: روش بررسی، نتیجه، بررسی اجرا‌نشده و علت
تعارض یا مانع / اقدام بعدی و مالک:
```

بازبین برای هر معیار، نتیجه و شاهد ثبت می‌کند. Agent 0 پیش از پذیرش، مبنای بسته را با شاخه مقصد مقایسه می‌کند و بخش‌های متأثر از تغییر مبنا را دوباره بررسی می‌کند. پذیرش به یک بازنگری و SHA مشخص تعلق دارد. تحویل فقط با ارجاع به نتیجه و ثبت نظر بازبین بسته می‌شود.

## وضعیت AMS

نسخه محلی V2 0.6.0 با `doctor` نصب و پایگاه داده را verified گزارش کرد. `status` مقدار `operational: false` و مرحله `vertical_task_path` را برگرداند. رجیستری نصب‌شده فقط نوع `internal` با runtime برابر `python-worker` و providerهای داخلی `text.echo` و `math.sum` را قبول می‌کند. نقش‌های این مخزن با تحویل دستی اجرا می‌شوند و به‌عنوان Worker نمونه ثبت نمی‌شوند.
