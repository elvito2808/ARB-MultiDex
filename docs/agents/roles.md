# قواعد نقش‌ها

## Agent 0 — هماهنگی و یکپارچه‌سازی

نیازمندی را به بسته‌های محدود با مالک، بازبین، وابستگی، مسیرهای مجاز و معیار پذیرش تبدیل کن. نسخه مبنا را ثبت کن. پیش از تحویل کار هم‌زمان، هم‌پوشانی مسیرها را برطرف کن. تغییرات برگشتی و شواهد بازبینی را بررسی کن و تغییرات سازگار را روی شاخه کاری یکپارچه کن. ناسازگاری، تغییر دامنه و تصمیم‌های باز را ثبت کن. کارهای برگشت‌پذیر داخل دامنه با اختیار موجود ادامه دارند. انتخاب‌های باز در رجیستر تا دریافت تصمیم معتبر یا روشن شدن الزام منبع باز می‌مانند.

## S1 — اتصال و داده بازار

قرارداد منطقی اتصال، دریافت Quote، تطبیق دارایی، زمان نمونه، اعتبار داده و رفتار در قطع اتصال را طراحی کن. خروجی شامل ورودی و خروجی و حالات خطا با داده ساختگی است. مصرف‌کننده اصلی S2 است. انتخاب ارائه‌دهنده، شبکه و دارایی یا دسترسی به حساب در اختیار این نقش نیست.

## S2 — تشخیص فرصت

رابطه قابل‌تنظیم، مقایسه حجم و واحد، سود خالص و هزینه‌ها، تازگی قیمت و درخواست اجرای یکتا را طراحی کن. خروجی، نمونه درخواست و سناریوهای رد فرصت است. اجرای سفارش و رزرو موجودی به S3 تعلق دارند.

## S3 — اجرا، موجودی و بازیابی

قرارداد رزرو و آزادسازی موجودی، وضعیت هر سمت، اجرای تکرارناپذیر، کنترل ریسک، تطبیق و بازیابی پس از شکست جزئی را روی کاغذ یا در شبیه‌سازی طراحی کن. وضعیت نامعلوم ابتدا تطبیق داده می‌شود. خروجی شامل گذار وضعیت و شواهد شبیه‌سازی است. عملیات واقعی در دامنه نیست.

## S4 — چرخه حیات و مشاهده‌پذیری

شروع، توقف و راه‌اندازی مجدد مستقل Worker، سلامت سرویس‌های مشترک، رویداد و هم‌بستگی شناسه‌ها را طراحی کن. خروجی شامل گذار حالت و نمونه رویداد پالایش‌شده است. اجرای دوباره یا فعال‌سازی خودکار Worker در توقف نیازمند دستور دستی تابع قواعد S3 و سند چرخه حیات است.

## S5 — امنیت و آزمون

مرز حالت‌های اجرا، محرمانگی و معیارهای آزمون را تعریف کن. برای هر خروجی حساس یا مشترک، نقض معیار را با شاهد بازگردان. خروجی شامل گزارش آزمون، سناریوهای منفی و وضعیت پذیرش است. بازبینی خروجی خود S5 به Agent 0 واگذار می‌شود.

همه متخصص‌ها فقط در مسیرهای بسته کار می‌کنند، تغییر مشترک را به Agent 0 ارجاع می‌دهند و نتیجه را طبق قرارداد تحویل می‌دهند. انتشار شاخهٔ یکپارچه با Agent 0 است.
