# ماتریس مسئولیت

مالک، تهیه‌کننده خروجی است. بازبین شواهد و سازگاری را بررسی می‌کند. Agent 0 وضعیت پذیرش خروجی و وابستگی‌ها را ثبت می‌کند.

| خروجی | مالک | بازبین | مشورت |
| --- | --- | --- | --- |
| مبنا، تخصیص، تعارض و یکپارچه‌سازی | Agent 0 | متخصص‌های متأثر | مالک پروژه برای تغییر دامنه |
| اتصال، DEX و سناریوی مرجع KuCoin | S1 | S2 | S3، S5 |
| تشخیص فرصت و درخواست اجرا | S2 | S3 | S1، S5 |
| اجرا، موجودی، ریسک و بازیابی بر پایه ۱٫۰ و ۱٫۱ | S3 | S5 | S2، S4 |
| چرخه حیات، Logging و Monitoring | S4 | S5 | S3 |
| امنیت و آزمون سرتاسری | S5 | Agent 0 | S1 تا S4 |

| حداکثر سه تلاش در مجموع برای هر سمت | [اجرا ۱٫۰، بخش سیاست تلاش](../../Execution_and_Balance_Management_Requirements_v1.0.md) و [الحاقیه ۱٫۱](../../Execution_and_Balance_Management_Requirements_v1.1.md) | تلاش اولیه داخل سقف است و بازیابی شمارنده را صفر نمی‌کند. سیاست Approval مستقل است |
