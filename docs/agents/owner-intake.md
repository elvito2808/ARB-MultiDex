# ورودی مالک برای آغاز توسعه

هر مورد می‌تواند با مقدار مشخص، گزینه‌های قابل بررسی یا «هنوز تعیین نشده» پاسخ داده شود.

| موضوع | ورودی مورد انتظار |
| --- | --- |
| هدف و اولویت نسخه اول | سناریوی اصلی، خروجی مورد انتظار و معیار موفقیت شبیه‌سازی |
| بازارها و شبکه‌ها | DEX و CEX مورد نظر، شبکه و محیط هر اتصال، بازارها و محدودیت دسترسی |
| دارایی و رابطه | جفت‌ها، واحد تسویه، جهت‌های مجاز و رابطه‌های اولویت‌دار |
| قراردادها | نسخه پروتکل و شناسه یا نشانی عمومی قراردادها به تفکیک شبکه، در صورت تعیین |
| فناوری | ترجیح یا محدودیت زبان، محیط اجرا و ذخیره وضعیت |
| سیاست شبیه‌سازی | حجم، سود خالص، هزینه، تازگی داده، محدودیت‌های ریسک و سناریوهای شکست |
| عملیات و آزمون | انتظارات توقف، بازیابی، گزارش و اعلان، سناریوهای پذیرش و موارد خارج از نسخه اول |

Agent 0 پاسخ‌ها را به [تصمیم‌های باز](decisions.md) و بندهای اسناد مبنا وصل می‌کند، تعارض‌ها را برای مالک ثبت می‌کند و پس از روشن شدن وابستگی هر بسته، تحویل آن را آماده می‌کند. نام‌های موجود در اسناد، سناریوی مرجع هستند. انتخاب محصول با مالک باقی می‌ماند.

## مرز توسعه

دامنه فعلی مستندات، طراحی غیرعملیاتی و شبیه‌سازی با داده ساختگی است. اتصال عملیاتی، فعال‌سازی یا استقرار LIVE، سفارش و امضای واقعی، انتقال دارایی و استفاده یا ثبت اطلاعات محرمانه خارج از دامنه هستند. انتخاب صرافی، شبکه یا قرارداد به‌تنهایی مجوز LIVE ایجاد نمی‌کند. بررسی ورود به LIVE به تصمیم صریح و جداگانه مالک درباره تغییر دامنه و ثبت معیارها و شواهد امنیت و آزمون نیاز دارد. برای تکمیل این فرم فقط اطلاعات عمومی و ترجیحات محصول ارسال شود.
