## Evidence and verification method

I compared the pinned requirements and handoff with the target diff, read the pinned Pair interface, Pair implementation and factory, and cross-checked the official chain, deployments, reserve, quote and fee references. Independently replayed Mirror metadata GETs, unsigned historical Mirror calls and relay reads at block 102699974. I rebuilt the router view arguments for official router `0.0.3045981`, with USDC → WHBAR for BUY and WHBAR → USDC for SELL. I decoded the result words, rederived both formulas from the Pair invariant, ran integer checks for the historical and synthetic examples, and hashed the Mirror runtime. The research document contains the request templates. [Reviewed evidence](https://github.com/elvito2808/ARB-MultiDex/blob/38be85dd629ca55e34dd165440e169e0c95215a7/docs/research/hedera-saucerswap-v1.md)
